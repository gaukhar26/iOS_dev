# iOS Development — Gaukhar

iOS projects built in Swift and UIKit: a full movie app plus course assignments.

## 🎬 CineScope — featured project

**CineScope** is an iOS app for movie lovers, in the spirit of Kinopoisk / IMDb.
I designed the app and developed the iOS front-end.

### Features
- **Premieres** — new releases on the home screen
- **Search** — find any movie by title
- **Genre filters** — browse movies by genre
- **Ratings** — see each movie's rating at a glance
- **Trailers** — open a movie's trailer on YouTube
- **Movie details** — description, genre, rating and more
- **Favorites** — save movies to watch later

### Design
The full UI was designed by me in Figma before development: visual style, screens and user flows.

### Tech
- Swift, UIKit (Storyboards)
- [TMDB API](https://www.themoviedb.org/) for movie data and posters
